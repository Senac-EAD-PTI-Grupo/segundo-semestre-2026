# 📋 Sistema de Gestão de Clientes (CRM Simplificado)

> **Projeto Integrador** — Aplicação web leve para cadastro, consulta, edição e exclusão de clientes com armazenamento local no navegador.

---

## 📌 Sobre o Projeto

Microempreendedores Individuais (MEIs) e pequenos prestadores de serviços frequentemente enfrentam dificuldades para organizar suas informações de clientes. Este projeto visa oferecer uma solução simples, intuitiva e sem necessidade de infraestrutura de servidor, utilizando a API de **LocalStorage** do navegador para a persistência dos dados.

## 🚀 Funcionalidades

- [x] **Cadastro de Clientes:** Nome, CPF, e-mail e telefone com validação de campos.
- [x] **Listagem e Consulta:** Exibição centralizada dos registros.
- [x] **Filtro de Busca:** Pesquisa rápida por Nome ou CPF.
- [x] **Edição e Exclusão:** Atualização e remoção de registros da base.
- [x] **Persistência Local:** Dados salvos automaticamente via `LocalStorage`.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Armazenamento:** Web Storage API (`LocalStorage`)
- **Controle de Versão:** Git & GitHub
